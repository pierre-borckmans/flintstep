# Security

Please don't open a public issue for a security problem.

Report it privately through GitHub: the repository's **Security** tab > **Report a
vulnerability**. If that isn't available, email pborckmans@gmail.com with "security" in
the subject.

Say what you found, how to reproduce it, and which version (Settings shows it). I'll
reply within a week and keep you posted until it's fixed. The fix ships in the next
release, and the advisory credits you unless you'd rather it didn't.

Only the latest release gets fixes.
